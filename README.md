# kanafix

kanafix はリモートデスクトップ（RDP）経由の日本語入力で起きる文字の二重化を補正する、Windows 用の常駐ツールです。iPad や iPhone の Windows App から Windows へ日本語を入力すると、Windows 11 の新しいメモ帳では変換を確定した瞬間に読みが消え残り、変換結果と混ざって残ります。

たとえば「変換が入るとおかしくなる。」と入力すると、メモ帳にはこう出ます。

```
へんかんがはいるとおか変換入るとおかしくなる。
```

## 導入と起動

1. [Releases](https://github.com/misc1999/KanaFix/releases) から `kanafix.exe` を入手します。
2. PowerShell でハッシュを確かめ、ダウンロード由来のブロックを外します。

   ```powershell
   # Releases の SHA256SUMS.txt と一致するか確認する（大文字小文字の違いは無視してよい）
   Get-FileHash .\kanafix.exe -Algorithm SHA256

   # ダウンロードしたファイルに付く実行制限（Mark of the Web）を外す
   Unblock-File .\kanafix.exe
   ```

3. `kanafix.exe` を実行します。初回起動時に、exe と同じフォルダーへ設定ファイル `kanafix.toml` を生成します。
4. メモ帳を前面にして日本語を入力し、二重化が消えていることを確認します。

配布元を確認できない実行ファイルには、Windows が SmartScreen の警告を表示します。ハッシュが `SHA256SUMS.txt` と一致していれば、「詳細情報」から「実行」で起動できます。

終了は起動したコンソールウィンドウで Ctrl+C です。終了した時点で補正はなくなり、素の入力に戻ります。

## 設定

設定項目は `kanafix.toml` の2つです。次の例のコメントは説明のためのもので、生成されるファイルには付きません。

```toml
apps = ["notepad.exe"]   # 補正するアプリの exe 名。複数指定できます
pace_ms = 6              # 送り直しの間隔（ミリ秒）
```

`pace_ms` は送り直す入力イベント1件ごとの待ち時間です。二重化が残る場合は 12、20 と伸ばします。間隔を広げるほど補正は確実になり、入力が画面に出るまでの遅れも増えます。

`apps` には補正の対象とするプロセス名を指定します。大文字小文字の違いは無視されます。メモ帳以外で同じ症状が出る場合は、そのアプリのプロセス名を追加します。プロセス名はタスクマネージャーの「詳細」タブで確認できます（例: `notepad.exe`）。

複数のアプリを対象にするときは、カンマで並べます。

```toml
apps = ["notepad.exe", "code.exe", "wt.exe"]
```

設定ファイルの読み込みは起動時のみのため、変更後は kanafix を起動し直します。

## 二重化の原因と補正のしくみ

iPad や iPhone の Windows App は Windows 側の IME を使いません。日本語変換を端末の中で完結させ、確定した文字だけを Unicode として Windows へ注入します。変換を確定するたびに、先に入力した読みを Backspace で消去してから変換結果を注入します。この一連の入力が確定の瞬間だけミリ秒間隔のかたまりになって届きます。

二重化が起きるのは Windows 11 の新しいメモ帳が読みの消去を終える前に次の文字を受け取るためです。消え残った読みの後ろに変換結果が入ります。従来の入力欄はこのかたまりを処理し切るため、同じ入力でも二重化しません。実測の記録は [`docs/rdp-input-analysis.md`](docs/rdp-input-analysis.md) にあります。

kanafix はこの Unicode 文字と Backspace のイベントを横取りし、既定で 6 ミリ秒ずつ間隔を空けて送り直します。メモ帳は消去を処理し終えてから次の文字を受け取るので、読みが残らなくなります。

## 制約と注意

- 補正が働くのは対象アプリが前面にあるときだけです。扱うキーは Unicode 文字の入力と Backspace の2種類に限られ、他のアプリや他のキーには介入しません。
- Backspace は発生源を区別せずに扱います。対象アプリが前面にある間は物理キーボードで押した Backspace も同じ経路を通り、1件ずつ間隔を空けて送り直すため、押しっぱなしにしたときの連続削除がわずかに遅くなります。
- 管理者権限で動作するアプリを対象にする場合は、kanafix も管理者として起動します。権限が下のプロセスから送り直した入力は、対象アプリのウィンドウに届きません。
- キー入力の記録や保存は行いません。横取りしたイベントをそのまま送り直すだけで、ファイルにもネットワークにも書き出しません。

## ビルド

```powershell
cargo build --release
# 出力: target\release\kanafix.exe
```

exe 単体で動作します。設定ファイルは初回起動時に生成されます。
